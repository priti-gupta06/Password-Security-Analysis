## Overview
This project focuses on analyzing password security principles and creating an organizational Password Security Policy.
It explains how strong authentication practices help protect accounts and sensitive information.

## Objective
- Understand strong password practices.
- Learn the importance of password uniqueness.
- Understand the use of password managers.

## Common Password Security Risks

- Password Reuse : One stolen password can be used to access multiple accounts.
- Weak Passwords : Short and predictable passwords are easier to guess or crack.
- Credential Theft : Phishing and malware can steal login credentials.
- Password Sharing : Sharing passwords reduces account security and accountability.
- Unsafe Storage : Storing passwords in plain text can expose them to unauthorized users.

## What is MFA?

Multi-Factor Authentication (MFA) is a security method that requires two or more verification factors.

Examples:
- Something you know — Password or PIN
- Something you have — Phone or security key
- Something you are — Fingerprint or biometric verification

## Interview Questions

 1. What makes a password strong?
A strong password is long, unique, difficult to guess, and does not contain easily available personal information.

 2. Why should a password be unique?
A unique password prevents attackers from using one stolen password to access multiple accounts.

 3. What is MFA?
MFA is an authentication method that uses two or more different verification factors to provide an additional layer of security beyond a password.

## Conclusion

Using long and unique passwords, password managers, and MFA helps reduce the risk of unauthorized access and credential-based attacks. 
Good password practices are an important part of organizational cybersecurity.
